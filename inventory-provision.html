Inventory provision report

Provision for slow-moving stock, batch by batch.

Sample data

Tap the visual to view it larger

Context
Finance needed to set money aside for slow-moving stock, looking at every batch of product received rather than each item overall. An early version of the report kept failing to load.
Action
I rebuilt the report on a cleaner data structure that shows each batch with its age, how much to set aside, and the dollar amount.
  • Wrote the SQL in Databricks that brings in every receipt layer with its cost, receipt date and age bucket
  • Fixed the link between tables that was causing the loading errors
  • Added a simple count of storage locations per item
  • Shaded the provision columns so reviewers can jump straight to them
Result
Reviewers get each batch's age, the amount to set aside and the dollar value in one report that loads reliably, and can jump straight to the shaded provision columns.
Learning
When a report won't load, the problem is often how the data is connected, not the formulas. Fixing the structure solved what increasingly complicated formulas couldn't.

SQL, DatabricksOne row per receipt layer of stock, with its cost and an age bucket for the provision report. Table, customer and location names are changed.

Scroll sideways to see full lines

SELECT
    CONCAT(s.company_id, '-', s.location_id, '-', s.item_id) AS item_key,
    cl.receipt_date,
    cl.qty                                                   AS layer_qty,
    cl.unit_cost,
    cl.layer_cost,
    -- aged as of the day the snapshot is pulled
    CASE
        WHEN cl.receipt_date IS NULL                              THEN NULL
        WHEN MONTHS_BETWEEN(CURRENT_DATE(), cl.receipt_date) < 6  THEN '< 0.5 Year'
        WHEN MONTHS_BETWEEN(CURRENT_DATE(), cl.receipt_date) < 12 THEN '0.5-1 Year'
        WHEN MONTHS_BETWEEN(CURRENT_DATE(), cl.receipt_date) < 18 THEN '1-1.5 Years'
        WHEN MONTHS_BETWEEN(CURRENT_DATE(), cl.receipt_date) < 24 THEN '1.5-2 Years'
        ELSE '2+ Years'
    END                                                      AS age_bucket
FROM item_inventory_snapshot AS s
-- one row per cost layer (each receipt of stock)
LEFT JOIN inventory_cost_layers AS cl
    ON  cl.item_key = s.item_key
    AND cl.valid_to IS NULL
